## 4요소

| 칸 | 내용 |
|---|---|
| **문제** | 프로그래밍을 배우지 않은 학생이 AI 도구만으로 프로젝트를 만들다 막히면 — 빌드 실패 · 예상과 다른 값 · 데이터 흐름 끊김 · DB · 페이지 이동 오류 등등 — 에러 문구를 읽을 수 없어 **어디가 잘못됐는지도, AI 에게 뭐라고 시켜야 하는지도 모른다** (판정 필요: "DB") |
| **대상** | 이 수업을 들은 학생 19명 — 3~4명씩 5팀 · 프로그래밍 경험 없음 · AI 활용법만 배움 · Next.js + Vercel + Neon 으로 팀 프로젝트 진행 · 기간은 주말 포함 9일 |
| **현재해법** | 에러를 통째로 AI 에 붙여넣고 "고쳐줘"를 반복 · 단톡방에서 강사에게 질문 · 검색(영어 문서) |
| **불편** | "고쳐줘" 반복이 다른 곳을 망가뜨린다(AI 가 원인을 지어낸다) · 강사 답을 기다리는 동안 팀이 멈춘다 — AI 활용해서 개발할 때 **파트 분배 문제 · git 형상관리 문제**로 자주 멈출 것 같다 · 같은 질문이 팀마다 되풀이된다 |

## 한 문단으로

프로그래밍을 배우지 않고 AI 활용법만 배운 학생 19명이 3~4명씩 5팀으로 9일 동안 Next.js · Vercel · Neon 으로 팀 프로젝트를 만든다. 막히면(빌드 실패 · 예상과 다른 값 · 데이터 흐름 끊김 · 페이지 이동 오류) 에러 문구를 읽지 못해 어디가 잘못됐는지 모르고, "고쳐줘"를 반복하다 AI 가 다른 곳을 망가뜨린다. 파트 분배와 git 형상관리에서도 자주 멈추며, 강사에게 물으면 답을 받을 때까지 팀이 멈추고 같은 질문이 팀마다 되풀이된다.

## 강사가 정한 것

- 공개 범위 — 수강생만
- 게시판은 수업용 계정을 만들어서 제공한다 (판정 필요: "계정")
- 질문할 때는 정확한 문제 진단을 위해 **무엇이 · 언제 · 어떻게 · 예상 값 · 실제 값** 등을 작성하게 유도한다
- 게시판에는 강사와 학생들도 대답할 수 있다

## 사이트가 내놓는 것

- [제안] 모든 답은 **"다음에 AI 도구에 붙여넣을 프롬프트"** 로 끝난다 — 코드 조각 · 파일 이름 · 명령어를 학생에게 직접 주지 않는다 (근거: 대상 칸 "프로그래밍 경험 없음" — 코드를 주면 현재해법의 "고쳐줘" 반복으로 돌아간다)
- [제안] 학생 프로젝트(GitHub · Vercel · Neon)에 사이트가 직접 접속하지 않는다 (근거: 선택한 세 형태 모두 접속이 필요 없다)
