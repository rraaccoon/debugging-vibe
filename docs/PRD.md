> 문서: PRD.md · 상태: 초안(1차 개발 반영) · 열린 질문 [?] 있음 · 마지막 갱신: 금
> 이 문서를 읽는 에이전트에게: 여기 없는 것은 지어내지 말고 질문으로 돌려라. 「안 만드는 것」에 있는 것은 만들지 않는다.

## 1. 만드는 것 (1차)

| 기능 | 하는 것 | 주소 |
|---|---|---|
| 증상별 해결 가이드 | 홈에서 자주 생기는 유형 8개 중 하나를 고르면 그 유형의 증상만 보인다(강사 결정: 한 페이지에 다 넣지 않는다). 증상 → 원인 → 먼저 확인할 것 → AI 도구에 붙여넣을 프롬프트(복사 버튼). 내용은 `src/content/guides.ts` 를 강사가 직접 고친다 | `/` (유형 고르기) · `/guide/[유형]` |
| 점검 체크리스트 | 파트 나누기 전 · AI에게 시키기 전 · DB 붙이기 전 · 합치기 전 · 배포 전. `src/content/checklists.ts` | `/checklist` |
| 정보 공유 | AI 를 잘 쓰는 법 — 습관 5개 · 규칙 파일 · 스킬 · 훅 · 에이전트 · MCP 의 무엇/언제/주의 · 요즘 많이 쓰는 도구 · "많이 붙일수록 망하는 이유"(강사 요청). `src/content/tips.ts` | `/tips` |
| 질문 게시판 | 증상 한 줄 + 무엇을 하다가 · 언제부터 · 어떻게 했나 · 예상 값 · 실제 값 (01 강사 결정). 강사와 학생이 답한다. 강사 답은 색으로 구분. 목록은 질문마다 카드로 나누고, 보기 화면은 「질문」 · 「답」 표로 가른다 (강사 요청 · 월) | `/board` · `/board/new` · `/board/[id]` |
| 로그인 | 수강생만(01). 강사 계정과 학생 공용 계정은 강사가 만든다 — `npm run user:add -- 이름 비밀번호 [instructor\|shared]` | `/login` |
| 별 수 자동 갱신 | 정보 공유의 저장소 순위를 매일 08:30(한국 시간) 에 GitHub 에서 다시 읽어 `src/content/tips.ts` 의 숫자만 고치고 main 에 커밋한다 — Vercel 이 그 커밋으로 자동 배포. 설명 문장과 목록은 강사가 손으로 고친다 (강사 결정: 별 수와 순서만 자동) | `.github/workflows/update-stars.yml` · `scripts/update-stars.ts` |
| 새 질문 슬랙 알림 | 질문이 올라오면 슬랙 채널에 쓴 사람(닉네임) · 제목 · 링크를 보낸다. Slack 앱의 Incoming Webhook 을 쓴다(무료 플랜에서 됨 — Workflow Builder 웹훅은 유료). 환경변수 `SLACK_WEBHOOK_URL` 이 없으면 알림 없이 그대로 동작한다 (강사 요청 · 월) | `src/lib/actions.ts` createPost |
| 스크린샷 붙이기 | 질문 쓰기 · 답 남기기에서 화면을 캡처해 붙여넣기(Ctrl+V)하면 스크린샷이 함께 올라간다. 파일 고르기 버튼은 없다(강사 결정: 업로드가 아니라 붙여넣기 느낌). 브라우저에서 가로 2000px · WebP 로 줄여 Neon DB 에 그대로 저장한다(강사 결정: 새 서비스 없이). 글 하나에 5장까지, 보기 화면에서 누르면 원본이 새 탭에 (강사 요청 · 월) | `/board/new` · `/board/[id]` · `/board/image/[id]` |
| 이모지 반응 | Slack 처럼 질문과 답에 이모지를 남긴다 — 누르면 달리고 다시 누르면 빠지며, 같은 이모지는 개수로 묶이고 마우스를 올리면 누가 눌렀는지 보인다. 자주 쓰는 40개 그리드 + 아무 이모지나 붙여넣는 칸(운영체제 이모지 자판, 강사 결정: 정해진 몇 개가 아니라 아무 이모지). ✅ 해결 됨 · 🔄 해결 중 같은 상태 표시로 쓰고 목록에도 보인다 (강사 요청 · 월) | `/board/[id]` · `/board` |
| 내 계정 만들기 | 학생은 공용 계정으로 처음 들어오면 바로 닉네임(로그인 ID) · 이름(강사만 봄) · 비밀번호를 정해 자기 계정을 만든다 (강사 결정) | `/setup` |
