# PRD — 디버그 119 (바이브 코딩 막힘 가이드)

> 문서: PRD.md · 상태: 초안(1차 개발 반영) · 열린 질문 [?] 있음 · 마지막 갱신: 금
> 이 문서를 읽는 에이전트에게: 여기 없는 것은 지어내지 말고 질문으로 돌려라. 「안 만드는 것」에 있는 것은 만들지 않는다.

> 강사 결정(금): 기획 문서를 촘촘히 쓰지 않고 01 · 02 만으로 1차 개발을 한다. 수정 범위는 강사가 개발 결과를 보고 말한다. 이 문서는 1차 개발에서 만든 것을 그대로 적은 것이다.

## 0. 디자인 컨셉 — 소방차가 불을 진압한다 (강사 결정 · 월)

학생의 막힘 = 불, 사이트 = 소방서. 색은 소방차 빨강(사이렌) · 물빛 파랑(해결 · 버튼 · 강사 답) · 불꽃 주황(미해결) · 형광 노랑 반사 띠 · 연기빛 회색 바탕. 홈 첫 화면에 소방차가 불에 물을 뿌리는 벡터 그림(`src/components/art.tsx`)을 두고, 모든 화면 아래에는 소방서 앞 거리 배경(`src/components/fire-background.tsx`: 소방서 · 소화전 · 호스 든 소방관 · 서 있는 소방차, 흐르는 구름)을 연하게 깐다 (강사 요청 · 월). 소방차가 지나가는 애니메이션은 뺐다 (강사 요청 · 화). 움직임 줄이기 설정이면 구름도 멈춘다.

| 화면 | 소방 이름 | 예전 이름 |
|---|---|---|
| `/` · `/guide/[유형]` | 진압 매뉴얼 | 증상별 가이드 |
| `/checklist` | 예방 점검 | 체크리스트 |
| `/board` · `/board/new` · `/board/[id]` | 출동 요청 · 신고하기 · 출동 보고 | 질문 게시판 · 질문 올리기 · 답 |
| `/tips` | 소방 교육 | 정보 공유 |

질문의 진압 상태는 따로 저장하지 않고 이모지 반응에서 읽는다(`src/lib/status.ts`): 💧 또는 ✅ 가 있으면 진압 완료, 🚒 또는 🔄 가 있으면 출동 중, 아니면 불남. 목록 카드의 왼쪽 띠와 배지가 그 상태다. 강사 호칭은 (소방관).
